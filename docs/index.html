LAB NOTES / BUILD → RUN → VERIFY

What to check
before Part 2.

AI가 만든 코드를 그대로 믿지 않고, 요구사항과 실행 결과를 대조하는 체크리스트입니다.

MISSION 01Read safely+

UTF-8-SIG, UTF-8, CP949를 순서대로 시도하고 `text` 컬럼과 업로드 상태를 확인합니다.

MISSION 02Clean the field+

copy → trim → null / blank / duplicate 제거 → index reset. 처리 전후 행 수를 비교합니다.

MISSION 03Meet the data+

문장 길이 통계와 랜덤 샘플을 먼저 읽습니다. 한 문장에 여러 주제가 섞였는지도 확인합니다.

MISSION 04Make meaning numeric+

multilingual MiniLM으로 embedding을 만들고, 의미가 가까운 문장과 다른 문장의 cosine similarity를 비교합니다.

MISSION 05Cluster, then question+

k=7 K-Means를 실행한 뒤 cluster별 실제 문장을 읽고, silhouette score로 k=3~10을 다시 비교합니다.

MISSION 06Project + save+

PCA 2D scatter로 구조를 보고 `id`, `text`, `cluster`를 UTF-8-SIG CSV로 저장합니다. API Key는 필요하지 않습니다.
